# Silicon Directory (ai-sites-directory)

> Where are the AI-related websites, and what does each one do.

A directory of AI websites organized into 12 categories; the `ext` (extended domains) category **does not go on the site**. Each entry lists the official site, a one-line description, tags (closed vocabulary) and a reachability status.

## Size (computed from data — see the build scripts under `scripts/` and `_audit/gen-repo-docs.mjs`)

711 entries / 12 categories (of which 184 ext entries are not on the site; 527 entries / 11 categories are live), tag vocabulary of 92.

## Content map

- `nav-data.json` — **Single source of truth**: entries + categories
- `tags.en.json` — Tag vocabulary (closed enum) + English
- `descriptions.en.json` — Entry descriptions in English (key = entry name)
- `check-results.json` — External-link reachability results (generated by `check-links.mjs`)
- `content/*.md` — Category page copy

## What this repo does not do

- No entries without an official website
- No marketing speak (`d` must be self-evident from that official site)
- No dead links left standing: `retired` entries render as non-clickable

## Schema and validation

- Field schema: `SCHEMA.md`
- Validator: `validate.mjs (this repo has no scripts/; all scripts live at the repo root)` (non-compliant entries fail the build)
