# 硅基导航 · AI 网站目录

> https://nav.specul.com/

系统化收录 AI 相关网站。**当前 529 个条目，按 11 类组织**，每条附一句话说明与链接核验状态。

## 这是什么

一个**人工整理的索引与引述**，不是爬虫产物，也不是评测。

每条记录回答三个问题：这个站是什么、解决什么问题、现在还活着吗。

| 原则 | 说明 |
|---|---|
| 只索引，不搬运 | 只给外链与一句话说明，不复制站点内容 |
| 核验留痕 | 每条标注核验日期与状态（ok / 待确认 / 失效） |
| 保守判定失效 | 只有明确 `404`/`410` 才判失效；DNS 解析失败标「待确认」，不误杀 |
| 未知就说未知 | 不猜测、不填充 |

## 目录结构

```
index.html / site.css / brand.css / brand.js   ← 站点产物（Pages 根目录）
CNAME / robots.txt / sitemap.xml
content/<分类>.md        ← 内容源（Markdown，便于手工维护）
scripts/*.mjs            ← 构建与核验脚本
data/nav-data.json       ← 重新归类后的结构化数据
```

## 构建流程

```bash
# 1) 从 Specul 主站现有目录数据重新归类（输出 data/nav-data.json）
node scripts/build-nav-data.mjs

# 2) 链接核验（保守判定，输出 check-results.json）
node scripts/check-links.mjs 713

# 3) 生成 Markdown 内容文件
node scripts/gen-content.mjs

# 4) 生成站点（复用统一骨架 _sites/_template/shell.mjs）
node scripts/build-site.mjs
```

改内容请直接编辑 `content/<分类>.md`。
