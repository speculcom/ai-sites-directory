  3. 算指标时守住分母Guard the denominator when scoring

    先决定未判定、报错与超时样本是否进入分母，再算准确率等指标，并把计数和百分比一起给出。跳过比例偏高时先查原因，而不是先调门槛。Decide first whether unjudged, errored and timed-out rows enter the denominator, then compute accuracy and report counts together with percentages. If many rows are skipped, investigate the cause before moving the threshold.

  4. 设回归门槛并保留失败样本Set a regression gate and keep failing cases

    门槛写成相对上一基线的差值和允许波动区间，失败样本单独归档供复查。成本与时长用虚构估算并标明，不写成厂商承诺或实测吞吐。State the gate as a delta from the previous baseline with an allowed band, and archive failing cases for review. Mark cost and duration as fictional estimates rather than vendor promises or measured throughput.

怎样判断交付合格How to check the deliverable

  • 每个指标都有定义、分子与分母规则和数据来源；未判定样本单独计数，既不算通过也不算失败。Every metric has a definition, numerator and denominator rule and data source; unjudged rows are counted separately, never as a pass or a fail.
  • 两次运行可以对比：数据集版本、模型标识与判定标准都在记录里，改动可追。Two runs are comparable: dataset version, model identifier and judging standard are in the record, so changes are traceable.
  • 随包评分函数在含未判定样本的输入上给出与参考解一致的数字，全部未判定时返回无法计算。The bundled scoring function matches the reference on inputs that contain unjudged rows, and returns not-computable when nothing was judged.

失败后查哪里When it fails

  • 输出解析成功但字段缺失Parsing succeeded but fields are missing
  • 检索样本回不到原文Retrieved samples do not return to the source
  • 排队与延迟影响时长估算Queuing and latency distort duration estimates
